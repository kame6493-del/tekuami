# Google Play の申告の回答案(てくあみ 1.0.0 / jp.tekuami.app)

個人アカウントで出せる範囲に収めている: カテゴリは「健康&フィットネス」。服薬・疾患管理・診断のような医療の機能は無い(2026-10-04 ひとつぶ手帳はカテゴリ「医療」で否承認になった。申告を書き換えて通すことはしない)。

## 1. ヘルスコネクトの権限の申告(アプリのコンテンツ → ヘルスコネクト)

マニフェストに残している健康の権限は android.permission.health.READ_STEPS だけ(プラグインが宣言するほかの権限は tools:node="remove" で外した。aapt2 dump permissions で確認済み: INTERNET / health.READ_STEPS / ACTIVITY_RECOGNITION / VIBRATE / ACCESS_NETWORK_STATE / BILLING)。
書きこみ・バックグラウンド読み取り・過去データ(30日より前)の読み取りは宣言していない。

- 申告するデータ型: 歩数(Steps)の読み取り
- 使い道の区分: フィットネス・ウォーキング(歩数のトラッキング)
- 説明文案:
  「てくあみは歩数計です。ヘルスコネクトから日ごとの歩数を読み、その歩数に合わせてアプリの中の編み物(マフラーなど)を1段ずつ進め、日ごとの歩数の記録として表示します。歩数は端末の中だけに保存し、外部へ送信・共有・販売しません。書きこみは行いません。」
- 歩数が無いとアプリの中心の機能(編み物が進む・記録)が動かないことを書く。
- 権限の理由を見せる画面: プラグイン(@capgo/capacitor-health)の PermissionsRationaleActivity が ACTION_SHOW_PERMISSIONS_RATIONALE(Android 13 以下)と VIEW_PERMISSION_USAGE / HEALTH_PERMISSIONS の activity-alias(Android 14 以上)を受け、アプリに同梱した privacypolicy.html を表示する。
- 権限を聞く時点: 初回、色を選んだあとの「ヘルスケアとつなぐ」ボタンを押したとき(理由の一文を添えてから聞く)。

要件として確かめたこと(Google の Health Connect のポリシー・開発者向けガイドより。公開前に Play Console の画面の文言でもう一度確かめる)
- アプリが使うデータ型ごとに、Play Console で申告と理由が要る。申告に無い権限をマニフェストに残すと審査で止まる → READ_STEPS 以外は外した
- プライバシーポリシーに、健康のデータの扱い(何を読むか・何に使うか・共有しないこと)を書く → store/privacy.md
- 権限の説明を表示する Activity(上記)が要る
- 広告・販売・信用審査などへの利用は禁止 → 使っていない
- targetSdk 36・minSdk 26(ヘルスコネクトの SDK の要件)

## 2. 健康アプリの申告(アプリのコンテンツ → 健康に関するアプリ)

- 健康に関する機能: 「アクティビティとフィットネス(歩数のトラッキング)」だけにチェック
- 医療機器・診断・服薬・疾患管理・臨床: いいえ
- 政府機関の健康アプリ: いいえ

## 3. データ セーフティ

- データを収集しますか: はい
  - 健康とフィットネス → 「フィットネス情報」(歩数): 収集する。端末上でのみ処理(サーバーへ送らない)。目的「アプリの機能」。共有しない。任意ではなく、アプリの機能に必要
    ※Play の定義では「端末の外へ送るもの」が収集。歩数は外へ送らないので「収集しない」と答えてもよいが、ヘルスコネクトの申告と食い違わないよう、端末上だけで処理する旨を添えて「収集する(端末上で処理)」と答える案。Play Console の「エフェメラル/端末上で処理」の選択肢に合わせる
  - 購入履歴: RevenueCat(購入の管理)に送られる。目的「アプリの機能」。共有しない(処理者への送信は共有に当たらない)
  - アプリのアクティビティ・端末 ID: RevenueCat が購入の照合に使う匿名の ID。目的「アプリの機能」
- データは送信中に暗号化されますか: はい(RevenueCat は HTTPS)
- データの削除をリクエストできますか: アプリ内の「記録をすべて消す」で端末の記録を消せる。アカウントは無い
- 広告: 含まない

## 4. コンテンツのレーティング(IARC の質問票)

- カテゴリ: ユーティリティ・生産性・コミュニケーション・その他
- 暴力・性的表現・言葉づかい・薬物・ギャンブル: すべていいえ
- ユーザー同士のやり取り・位置情報の共有: いいえ
- デジタル商品の購入: はい(買い切りの App内課金)
- 見込み: 全年齢(IARC 3+ / CERO 相当 A)

## 5. そのほか

- 対象年齢: 13歳以上(子ども向けにはしない。ファミリー ポリシーの対象外にする)
- 広告 ID: 使わない(「広告 ID を使用しない」と申告)
- 政府・金融・VPN: 該当なし
- ACTIVITY_RECOGNITION: 端末の歩数センサーを読むための実行時の権限。申告フォームは不要(身体活動の権限は機密性の高い権限の申告対象外)
