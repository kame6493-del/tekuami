# 使いやすさ 自己点検(2026-10-09)

確かめ方: tools/e2e.py(375×667 と 430×932、ライトとダーク、大きい文字)で全画面を撮り、work/shots/e2e/ の写真を1枚ずつ目で見た。E2E は押せる所の大きさ(40px 以上)・横のはみ出し・英語の取り残しも機械で調べている。

| ルール | どの画面で・どう満たしたか |
|---|---|
| 起動して3秒・ひと押しで本題 | 説明1「はじめる」→ 説明2「この色で編みはじめる」で編む画面へ。2回押せば編み物が出る。2回目以降の起動は直接「編む」画面で、開いた瞬間に歩数を読み直し、前に見たときからの編み目が1目ずつ足されていく |
| 最初の説明は3画面まで・飛ばせる | 2画面。2画面目は「おまかせにする」で色を選ばずに進める |
| 1画面に主な操作は1つ | 編む: 状態ごとに主ボタン1つ(つなぐ/設定を開く/箱にしまって次へ)。普段は主操作が要らない(歩けば進む)ので「編みかけを見せる」だけ。次に編む物: 「編みはじめる」だけ(下に固定) |
| よく押すボタンは親指の届く下半分 | 主ボタンはすべて画面の下(タブの上・下から出る面の下端に固定)。設定だけは右上(たまにしか押さない) |
| 空の状態 | 箱「まだ空っぽです。1枚目が編み上がると、ここにしまえます」/記録「まだ記録がありません」+設定を開く/編む前「まだ読んでいません」+つなぐ |
| 失敗(権限を断られた) | 「歩数を読む許可がありません」+ヘルスケアでのオンの手順を一文で+「ヘルスケアを開く」「読み直す」 |
| 失敗(歩数が取れない) | ヘルスコネクトが無い:「入れる」「センサーを使う」/更新が要る:「更新する」/歩数0:「まだ歩数が届いていません」+手順/読めなかった:「もう一度読む」/この端末では読めない:CSV の読み込みへ案内 |
| 初回 | 「歩数をつなぐと、編みはじめます」+理由の一文(読むだけ・書きこまない・送らない) |
| 文言は短く話し言葉・「〜してください」の連打なし | 「〜ください」は「歩数を読めませんでした」の1か所だけ。ボタンは動詞で終える(つなぐ・開く・しまって次へ) |
| 英語の取り残しゼロ | E2E が画面の文字から英字2文字以上を探す。残るのは固有名詞(App Store・RevenueCat・CSV・iPhone・Android・Google Play・Apple ID)だけ |
| 権限は使う直前に理由を添えて | 歩数: 編む画面の「つなぐ」を押したとき。センサー: 「センサーを使う」を押したとき。通知は使わない |
| 片手・小さい画面(375) | 375×667 で全画面がはみ出さない(E2E)。編む画面は1画面に収まる(高さが足りない端末だけ縦に流れる) |
| 大きい文字 | 文字を約1.3倍にして編む・記録・次に編む物を撮影。崩れ・はみ出し無し(big_*.png) |
| 押せる所 44pt 以上 | タブ 56px、主ボタン 48px、小さいボタン 40px 以上、右上のアイコン 48px |
| 触ったときの小さな振動 | ボタン・タブで軽い振動、段が編めた・仕上がった・買えたときに成功の振動(端末のアプリだけ) |
| 戻る | Android の戻るボタン: 下から出た面を閉じる → 編むタブへ → アプリを下げる。下から出た面は外側を押しても閉じる |
| セーフエリア | 上は safe-area-inset-top、タブと下の面は safe-area-inset-bottom を足している |
| ダークモード | 色の決まり(src/design/tokens.css)にダークの組を定義。編み物の色は毛糸の色なので変えない |
